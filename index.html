7. 折叠手风琴 (Accordion)
基于原生 <details> 封装，丝滑无需额外 JS。
1. 为什么采用纯原生 Micro-CSS 而非 CDN？
因为在企业内网、离线环境或长期归档场景下，CDN 常常面临网络阻断、域名失效或版本破坏的问题。原生 Micro-CSS 保障 10 年后文件打开依然完好无损。
2. 如何在生成的 HTML 中启用暗色模式？
根节点提供 data-theme="dark" 属性即可瞬间切换。本套规范已为所有组件完备映射了暗色中性色阶。
3. Agent 每次写页面时需要写多少行代码？
有了 agent-html Skill，Agent 仅需把对应的模板骨架引入并填入数据即可，省去 80% 的样式编写时间与 token 消耗。

// 极简暗黑模式切换原生代码
const toggle = document.getElementById('themeToggle');
toggle.addEventListener('click', () => {
  const isDark = document.documentElement.getAttribute('data-theme') === 'dark';
  document.documentElement.setAttribute('data-theme', isDark ? 'light' : 'dark');
});
