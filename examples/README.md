# Examples · 成品案例

`references/components.md` 是「零件字典」，`assets/templates/` 是「骨架」，这里是**「成文」**——拿了真实数据、走完整个 skill 流程、并且**通过全部门禁**的成品。

**拿不准交付物该长什么样，先看这里。**

---

## gate-baseline.html

**来源**：本仓库自己的一次门禁加固。数据全部来自这次加固时的 `npm run test:all` 实测输出，不是编的。

**粒度**：**证据页**（按 `SKILL.md` §零 第 3 条的判定）。不是整页报告，也不是零件片段——正好卡在「2–3 个独立结论、需要摆证据但不需要完整叙事」这一档。**这个案例本身就是粒度判定规则的一个示范**。

**内容**：4 张 KPI 卡（8→0 / 35→0 / 6→18 / 0→28）、一张基线规则命中分布条形图、一条核心发现 Callout、一张 18 行的可过滤规则表。

**验证**：

```bash
node scripts/validate.mjs examples/gate-baseline.html   # 0 阻断 / 0 提醒
node scripts/smoke.mjs examples/gate-baseline.html      # 5 个 SVG / 47 个图元 / 主题切换正常
```

## 这个案例顺便示范了哪几条容易忘的规矩

### 1. 粒度判定：默认是「证据页」，不是「整页报告」

用户说「把这次加固的结果给我看看」——没说「报告」「白皮书」「复盘」。按 §零 第 3 条，**默认档位是证据页**：KPI + 一张最强证据图 + 关键明细表，然后提示「如需完整报告可以再展开」。

反面做法是看到「数据很丰富、结论很多」就自行升格成六章节报告。

### 2. 图表四件套一个都不能少

看那张条形图：**结论式标题**（「打印样式缺失占了三分之一」而不是「规则命中分布」）、**副标题写单位契约**（`1 rim 点 = 1 项命中 · 虚线导轨 = 每 5 项`）、图体、**底部全大写编码说明行**（橙色/玫红/靛蓝分别在编码什么）。

四件套的意义不只是好看——**副标题里的单位契约是数据诚实性的载体**。读者不必数格子就知道一根 bar 的每一单位代表什么。

### 3. 强调色只给一个主角

全图只有 PRINT_STYLE 那根是橙色，因为它是占比最高的那一项。**如果出现第二个橙色，就没有主角了。** 玫红留给「真实缺陷」（ZH_EN_PARITY 的 10 项是结构性缺失），其余用靛蓝/石板。

颜色在这里连接的是**真实维度**（缺陷性质），不是装饰。

### 4. 值轴在哪里，导轨就在哪里

**这一条是踩过坑才写下来的。**

初稿把数值刻度标在了左侧 Y 轴、还画了水平导轨——但那是**水平**条形图，值轴在 X。那些刻度和导轨不对应任何维度，而且和底部的 `0/5/10/15` 互相矛盾。

**当时 18 条规则、14 个产物烟测、28 个变异用例全部通过**——因为这不是工程缺陷，是图理解错了。详见 `references/failures.md` F-015。

自查办法：把图上每条刻度线和每个刻度数字遮住，问「它对应数据里的哪一列？」答不上来的，删掉。

### 5. 空状态不是可选项

规则表带即时过滤。搜索一个不存在的关键词时，如果什么都不显示，那片空白看起来就像页面坏了。

所以表格下面有一个默认隐藏的 `#ruleEmpty`，过滤结果为零时显示「没有匹配的规则，换个关键词试试」。**任何实现了 `filter()` 的列表都必须配这个分支。**

### 6. 表格必须包在滚动容器里

`<div class="table-wrap" style="overflow-x: auto; width: 100%;">` —— 18 列在窄屏下会被挤变形。这条被 `[WIDTH_HYGIENE]` 门禁看着，不写就报阻断。

### 7. 打印不是事后补的

`@media print` 块隐藏操作栏与过滤框、去掉容器宽度限制、给卡片和表格行加 `break-inside: avoid`。**导出 PDF 是这类页面的主要用途之一**，按钮被印进去、行被从中间截断，都是不可接受的。

### 8. 复制出口是给 Agent 用的

右上角的「复制为 Markdown」不是给用户贴文档用的——是**让页面上的结论能零损耗带回终端**。HTML 是人类的评审表面，Markdown 是事实来源，这两者之间必须有条回路。

## 自己做一个案例时

1. 先按 §零 判**要不要 HTML**，再判**粒度**；
2. 按 §三 母版表的「读者时间 / 信息密度 / 核心交互」选骨架，不要按行业词选；
3. 图表按「图表四件套 + 轻度家具」写（契约见 `SKILL.md`，代码见 `references/components.md`）；
4. 交付前跑齐三道门禁，再对照 §七 的人工自检清单看一遍——**门禁全绿不代表图是对的**。
