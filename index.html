Engineering Philosophy

Why Zero-CDN Standalone?

Comparing the three ways AI agents generate frontend interfaces.

The CDN Trap
Tailwind CDN Runtime
Models inject <script src="cdn.tailwindcss.com"> and Google Fonts.
  • ✕ Breaks in offline / air-gapped corporate intranets
  • ✕ 2-second JS parse delay causing FOUC layout shift
  • ✕ Fails under strict corporate Content-Security-Policies
  • ✕ Link rot causes page degradation over time
The Visual Slop Trap
Ad-Hoc Inline CSS
Forbidding CDNs leads models to hallucinate arbitrary inline styles.
  • ✕ Inconsistent pure-black harsh 1px borders
  • ✕ Oversized 30px unpadded tables and misaligned columns
  • ✕ Zero dark mode support; eye-burning white screens
  • ✕ Every session invents divergent CSS class names
The agent-html Standard
Native Micro-CSS Base
~75 lines of pure CSS variables and pre-tested semantic classes.
  • ✓ 100% offline; double-click in Finder to render
  • ✓ Instant 0ms load with zero runtime dependencies
  • ✓ Faithful shadcn Zinc-neutral aesthetic & tokens
  • ✓ Automatic Light/Dark mode with 5-line native toggle
