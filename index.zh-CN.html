对比

为什么不引 CDN，也不让 AI 随意写 CSS？

看下三种常见方式的区别：

CDN 依赖陷阱
引入 Tailwind CDN
AI 喜欢加上 <script src="cdn.tailwindcss.com">。
  • ✕ 断网或内网环境下直接白屏
  • ✕ 打开有明显卡顿和排版闪烁
  • ✕ 容易被浏览器的安全策略 (CSP) 拦截
  • ✕ CDN 链接一旦失效，历史文件就坏了
AI 视觉塑料陷阱
让 AI 随意手写 CSS
不给规范时，AI 自由发挥出来的样式通常很难看。
  • ✕ 边框生硬、间距混乱、没有设计感
  • ✕ 表格挤成一团，手机上没法看
  • ✕ 没有暗黑模式，晚上查看很刺眼
  • ✕ 每次生成的类名都随机乱变，没法维护
agent-html 方式
精简的原生 CSS
大约 75 行原生 CSS 变量与常用的基础样式类。
  • ✓ 纯离线单文件，双击秒开
  • ✓ 零依赖，不需要打包构建
  • ✓ 干净耐看的 shadcn 风格灰色调
  • ✓ 自带平滑好用的深浅色切换

日常提示词示例

触发母版：母版 01 (长文档审查报告)
“生成一个单文件 HTML 监控看板，展示生产 API 延迟与吞吐大盘。包含 4 列 KPI 统计卡、纯前端实时搜索过滤表格，以及原生弹窗交互。”
触发母版：母版 02 (数据监控大盘)
“记录今天网关故障的突发事故复盘与时间轴编年史。单轨垂直时间线排版，带有明确时间戳、操作人标签，并支持一键复制为 Markdown 归档。”
触发母版：母版 05 (时间轴与故障编年史)
“制作一个 4 列敏捷任务分拣拖拽看板，对这 20 个 Bug 工单按优先级进行分拣流转。支持纯原生 HTML5 跨列拖拽，并提供一键复制分拣决策回终端机制。”
触发母版：母版 06 (Bug 分拣与需求看板)
“制作一个模型 A 与模型 B（或 Prompt v1 vs v2）的横向并排对比评测矩阵。左侧基准右侧挑战者，下方列出量化差异 Delta 对照表与最终胜出判定。”
触发母版：母版 04 (并排对比矩阵)
“为这次排障调试会话创建一个左右双栏的 Master-Detail 查看器。左侧支持搜索过滤用例列表，右侧展示格式化 JSON Payload 并带有一键复制按钮。”
触发母版：母版 03 (双栏审查工作台)
